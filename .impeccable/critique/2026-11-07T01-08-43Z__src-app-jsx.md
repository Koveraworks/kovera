### Priority Issues

#### [P2] Supply-Side Asymmetry in Shift Explorer CTA
- **Why it matters:** The Shift Explorer action button currently only supports business owners: "Request this support", pre-filling the business waitlist. A worker browsing roles has no direct button to state "I want shifts like this".
- **Fix:** Add a secondary worker CTA button ("Available for this role") that pre-fills worker experience and opens the worker waitlist.
- **Suggested command:** `/impeccable polish src/App.jsx`

#### [P3] Modal Dialog Focus Trap
- **Why it matters:** While `Escape` key dismiss and ARIA dialog roles are present, keyboard focus is not trapped within the modal when open.
- **Fix:** Add a lightweight focus trap inside the modal dialog container for full WCAG AAA screen reader compliance.
- **Suggested command:** `/impeccable accessible src/App.jsx`

#### [P3] Phone Input Auto-Formatting Space Mask
- **Why it matters:** Users entering 10 digits see continuous text (`9876543210`) rather than grouped pairs (`98765 43210`).
- **Fix:** Add automatic formatting that inserts a space after the 5th digit for visual scanning ease.
- **Suggested command:** `/impeccable polish src/App.jsx`
